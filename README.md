## 👋 About

Most of what I ship lives in **private repositories**, so this page describes the work
instead of counting commits. The short version: I take language models out of the
notebook and wire them into systems that people depend on — queued jobs, retries,
permissions, audit trails, and a UI someone non-technical can actually use.

---

## 🤖 What I Work On

<table>
<tr>
<td width="50%" valign="top">

### LLM Systems in Production

- OpenAI and Groq integrations behind **queued job workers** — retries, timeouts, token and cost control
- **Speech-to-text pipelines**: audio ingestion, storage, transcription, post-processing
- **Agent and skill architectures** — declarative skill definitions, structured tool configuration, quality gates
- Prompt design and **structured output**, evaluated against real business cases rather than toy prompts

</td>
<td width="50%" valign="top">

### Machine Learning

- Feature engineering and dataset preparation from messy production data
- Training and evaluation loops, model selection, error analysis
- Serving models behind APIs and keeping them observable once deployed
- Reproducible experiment and deployment workflows

</td>
</tr>
<tr>
<td width="50%" valign="top">

### Data Engineering

- Collection pipelines with **Scrapy, Playwright, Selenium, Crawlee** — including targets that push back
- Processing and analysis with **pandas, NumPy, SciPy, PyArrow**
- **Streamlit** and **Flask** to put results in front of non-technical users
- SQLAlchemy, PyMongo, PostgreSQL, SQL Server

</td>
<td width="50%" valign="top">

### Platform & Backend

- **Django + DRF** and **NestJS + Prisma** services
- JWT auth, role and permission systems, multi-tenant data isolation
- Schema design in **PostgreSQL** and **SQL Server**; **T-SQL** and **PL/pgSQL** by hand
- CI and scheduled automation with **GitHub Actions**

</td>
</tr>
</table>

### Front-end, when the product needs it

**Angular** (Material, RxJS, Monaco) and **React** (Vite, Router) — I build the screens my APIs feed.
